# 机房教学策略配置工具 (Coding Lab Assistant - Portable Edition)

专为编程类教培机构、机房实训与学校课堂定制打造的系统管控与教学配置工具。

---

## 核心设计与定位

- **U 盘随身携带即插即用**：老师通过 U 盘直接在学生机上完成环境检查与策略部署；配置完成后拔掉 U 盘，工具不驻留学生电脑，防止学生自行运行修改。
- **视觉风格**：极简现代工业风，严格遵循 3 种中性色系（中性灰白底 `#F8FAFC`、深蓝灰主色 `#0F172A`、中性灰线 `#E2E8F0`），无 3D 凹凸复古感，无不明意义 emoji。

---

## 核心配置项目

### 1. Edge 浏览器访问策略
- **网址白名单锁定**：通过系统底层组策略（`URLBlocklist = ["*"]`），阻断一切未授权网站，仅放行允许的教学与考评系统（小宝科技站、xbyxz.cn、中国电子学会、Tinkercad）；点击【管理白名单】可增删规则。
- **桌面直达启动图标**：为桌面 Edge 快捷方式绑定启动参数直达目标网址，100% 绕过单机限制，双击直接直达。
- **离线冲浪游戏 (Surf)**：单独封禁 Edge 冲浪游戏。
- **文件下载限制**：阻止学生通过 Edge 私自下载无关文件。

### 2. Chrome 浏览器访问策略 (1:1 独立对照)
- **网址白名单锁定**：配置 Chrome 组策略，与 Edge 同步生效相同白名单。
- **桌面直达启动图标**：为桌面 Chrome 快捷方式绑定启动参数直达目标网址。
- **离线恐龙游戏 (Dino)**：单独封禁 Chrome 恐龙跳跃游戏。
- **文件下载限制**：阻止学生通过 Chrome 私自下载文件。

### 3. 桌面与文件系统规范
- **机构壁纸与锁屏**：部署统一壁纸与锁屏并锁定注册表，阻止学生擅自更换。
- **文件扩展名显示**：始终显示文件后缀名，彻底避免将 `code.py.txt` 误认为 `code.py` 的格式混淆。
- **隐藏“了解此图片”图标**：去除桌面聚焦冗余图标，保持桌面整洁。

### 4. 编程环境优化
- **Python pip 镜像源多源切换**：支持一键切换【清华源】、【阿里源】或【恢复默认】。
- **解除 Windows 长路径限制**：启用 `LongPathsEnabled`，解决嵌套依赖路径超过 260 字符报错。

## 打包命令

使用 `PyInstaller` 将本脚本打包为可放入 U 盘随身携带的单文件 `.exe`：

```powershell
pyinstaller --onefile --windowed --uac-admin `
  --add-data "bizhi.jpg;." `
  --add-data "system.ico;." `
  --add-data "whitelist.txt;." `
  --icon "system.ico" `
  --name="LabAssistant" one_assistant.py
```

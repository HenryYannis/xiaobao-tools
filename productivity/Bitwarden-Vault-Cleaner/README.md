# 🔐 Bitwarden 密码库去重清洗与 TOTP 扫码迁移工具 (Bitwarden Vault Cleaner)

100% 纯本地离线运行、零依赖的单文件 Bitwarden 密码库清洗审计工具。支持智能账号去重、明文核对密码、TOTP 动态验证码手机扫码迁移、Passkey 安全无损保留与标准 JSON 重新导出。

---

## 🌟 核心功能与特色

1. **🛡️ 100% 离线单文件运行，零网络请求**
   - 所有的解析、去重、二维码生成与清洗均在本地浏览器的内存沙箱中进行。
   - 不引入任何外部 CDN，没有后端服务器，断网也可完美运行，绝对保障密码库与凭证的最高隐私安全。

2. **🔍 智能多维账号去重**
   - 自动按照「域名 / 服务名 + 用户名」进行聚类，精准抓取重复账号。
   - 对于无网址记录（如部分政务、App 账号），智能结合标题与用户名精准聚合，避免错误合并。
   - **明文密码直观展示**：无需繁琐点击查看，所有待比对密码直接展示明文，方便一眼辨别新旧密码与有效账号。

3. **✨ 可靠防误删机制（实时标记与撤销）**
   - 点击「实时删除」仅在内存中打上中划线标记，卡片**绝不会突兀消失**。
   - 剩余有效账号会清晰标绿显示 **`✅ 最终保留`**，所有改动一目了然。
   - 提供「↩️ 撤销删除」按钮，随时可以一键反悔撤销。

4. **📱 TOTP 动态验证码扫码迁移看板**
   - 自动扫描并集中展示密码库中所有带有 TOTP 动态验证码的条目。
   - **标准二维码生成**：点击「弹出二维码扫码」，自动转换为符合 RFC 6238 及 Google Authenticator 规范的标准二维码。
   - **自定义网站名 (Issuer)**：弹窗内支持自由修改网站名称与账号标识，解决部分旧导出数据在谷歌验证码中不显示网站名的问题。修改时二维码实时更新。
   - **手机一扫即入**：兼容 Google Authenticator、微软 Authenticator、2FAS、Bitwarden Authenticator 等主流身份验证器。
   - **安全剥离**：手机扫码保存后，可单条或一键批量清空 TOTP 字段。

5. **🔑 Passkey (FIDO2) 凭据 100% 完整保留**
   - 严格保留条目中的 `fido2Credentials` 原生结构与公钥数据，在清洗去重与剥离 TOTP 的过程中绝不损坏任何 Passkey。

6. **⬇️ 一键导出清洗后的标准 JSON**
   - 处理完成后，点击右上角「导出清洗后的 Bitwarden JSON」，即可下载标准格式的 `.json` 导出文件，可直接重新导入回 Bitwarden 官方。

## 🚀 使用指南

### 第一步：从 Bitwarden 导出数据
1. 打开 Bitwarden 网页版或桌面端应用。
2. 进入 **设置 (Settings)** -> **导出保管库 (Export Vault)**。
3. 文件格式选择 **`.json`（未加密）** 并导出到本地。

### 第二步：运行本工具
1. 直接用任意现代浏览器（Chrome、Edge、Firefox 等）双击打开本目录下的 **`index.html`**。
2. 将刚才导出的 `.json` 文件拖入页面顶部的虚线拖拽区域中。

### 第三步：TOTP 迁移与密码去重
- **迁移动态码**：在页面上方的 **【TOTP 动态验证码迁移看板】** 中，点击账号右侧的「📱 弹出二维码扫码」，用手机上的身份验证器扫码录入；录入完毕后点击清空。
- **清理重复账号**：在下方的分组卡片中，明文核对密码，保留最新或正确的密码，点击多余条目右侧的「🗑️ 实时删除」。

### 第四步：导出并重新导入
1. 点击右上角绿色按钮 **「⬇️ 导出清洗后的 Bitwarden JSON」**。
2. 回到 Bitwarden，进入 **设置** -> **导入数据 (Import Data)**，选择格式为 **Bitwarden (JSON)**，选择刚导出的清洗文件完成导入即可。
